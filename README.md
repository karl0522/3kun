# 三坤牌

三国题材的昆特牌，手机网页版。规则以《巫师 3》里的昆特牌为蓝本，卡牌、势力和领袖全部换成三国人物。

当前版本：1.0

在线试玩：<https://3kun.05220522.xyz>

## 玩法

- 双方各带一副牌，开局抽 10 张手牌，可以换掉其中 2 张。
- 一场打三局，先赢两局的一方获胜。每局轮流出一张牌，谁过牌谁就不能再出；双方都过牌后比总战力。
- 每局结束后场上的牌全部清空，双方各抽 2 张牌进入下一局。
- 单位牌分近战、远程、攻城三排；天气牌会把一整排的战力压到 1；金卡猛将不受天气和大部分技能影响。
- 每位领袖有一个只能用一次的技能。

第一次进入对局会自动播放新手引导，对局中点右侧的"?"可以随时查看全部技能说明。

## 势力

| 势力 | 领袖 | 被动 |
| --- | --- | --- |
| 蜀汉 | 刘备、刘禅 | 每赢下一局，抽 1 张牌 |
| 曹魏 | 曹操、司马懿 | 平局时判自己胜 |
| 东吴 | 孙坚、孙权 | 站位为「灵活」的单位不受天气影响 |
| 黄巾 | 张角、张宝 | 每局结束时，随机保留 1 张己方单位在场 |
| 群雄 | 袁绍、马腾、孟获 | 第 3 局开始时，从弃牌堆随机召回 2 张单位上场 |

另有一组中立牌，任何势力都可以带。组牌规则：单位牌至少 22 张，特殊牌最多 10 张，中立牌最多 6 张，整副牌最多 32 张。

## 本地运行

纯静态网页，不需要安装依赖或打包，起一个静态服务器即可：

```bash
python -m http.server 8898
```

然后用浏览器打开 `http://localhost:8898/`。

## 目录结构

| 路径 | 内容 |
| --- | --- |
| `index.html` | 页面骨架和样式 |
| `data/cards.js` | 全部卡牌数据，唯一数据源 |
| `data/abilities.js` | 技能、领袖技能、势力被动、组牌规则的定义和说明文字 |
| `js/rules.js` | 规则引擎，纯数据，不依赖页面 |
| `js/effects.js` | 各技能和领袖技能的效果 |
| `js/ai.js` | 电脑对手（简单、普通、困难） |
| `js/ui.js` | 界面、动效、新手引导 |
| `img/sanguo/` | 卡图原图（1152×1536） |
| `img/sanguo-sm/`、`img/sanguo-md/` | 游戏里实际加载的缩小版卡图 |
| `tests/run.js` | 规则测试 |
| `tools/` | 数据校验、平衡模拟、批量调战力 |

## 开发

改完卡牌数据或规则后运行：

```bash
node tools/validate.js
```

```bash
node tests/run.js
```

查看各势力和领袖的胜率（电脑自己对打，参数是每组局数和难度）：

```bash
node tools/sim.js 150 hard
```

批量修改战力：

```bash
node tools/setpower.js 卡名=战力
```
